How to use this

From download to delivery in four steps.

01

Read the guide first

The Facilitator Guide has minute-by-minute timing, opening scripts, and talking points for all ten sessions. Start there.

02

Print the handouts

One Participant Handout Pack per person — ten fill-in worksheets that match each session. Print double-sided.

03

Load the decks

Open each session deck in PowerPoint. Animations advance on click. Swap the placeholder QR links for your own before delivery.

04

Run the program

Use the Program Toolkit for the pre-workshop diagnostic, the 30-day follow-up, and the before/after impact scorecard.
