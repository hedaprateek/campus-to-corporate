Workshop Hub — Admin

Sign in with a GitHub token to edit content and replace materials.

Create a fine-grained token at github.com/settings/personal-access-tokens: set Repository access to only campus-to-corporate, and under Repository permissions set Contents: Read and write. Give it an expiry date. Nothing else is needed.
The token is stored in this browser's local storage so you don't have to paste it each time. Anyone with access to this browser profile can use it to write to that one repository. Use Forget token on a shared machine, and let it expire.
