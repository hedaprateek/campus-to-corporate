How this works. This page has no server and never contacts the GitHub API — it edits the content in your browser and hands you a file. GitHub's own website does the committing, which is an ordinary page visit, so nothing here can be blocked by a proxy.
  1. Edit whatever you need below.
  2. Click Download content.json (or Copy JSON).
  3. Open the repository uploader and drop the downloaded content.json in. Keeping the same filename replaces the old one.
  4. Click Commit changes on GitHub. The site updates in about a minute.
Unsaved edits restored. You have changes from a previous visit that were never downloaded. Continue editing, or discard them.
MaterialsReplace a deck or document — same filename overwrites it ›
To replace a file: click Upload replacement next to it. That opens GitHub's uploader already pointed at the right folder — drag the new version in, keeping exactly the same filename, and commit. Every link on the site (and any link you have already shared) keeps working, because the path never changes.

Uploading a file with a different name adds it alongside the old one instead of replacing it. If you do that, update the matching Deck file path below and re-download the JSON.
